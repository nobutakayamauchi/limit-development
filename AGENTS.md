# AGENTS.md

## Repository role
Limit Development is the public front door and index for the developer's current work, lineage, public status, and links to canonical implementation/evidence repositories.

## Load order
1. Read `README.md`.
2. For any implementation claim, follow the referenced canonical repository instead of inferring technical truth from this index.
3. Load only the public page/status files needed for the current update.

## Source of truth
- This repository is canonical for the public index and presentation layer.
- Product/runtime/technical truth remains canonical in each linked implementation repository.
- Ultimate Loop is the canonical development-method repository unless a newer explicit supersession record says otherwise.

## Context budget
- Do not recursively load the whole linked ecosystem.
- Follow only the canonical repository relevant to the current claim.
- Historical lineage repos are reference-only unless the task explicitly needs reconstruction.

## Human gates
Publication, pricing, public claims, external links, visibility changes, deletion, and other public/external changes require explicit human approval.

## Stop conditions
Stop when a public statement conflicts with a canonical implementation repo, current status is unclear, or a requested update would present historical evidence as current operational truth.
