# 限界開発 / Limit Development

> **すべてを懸けて、一人の男がスマホ1台でクソッタレな世界と戦う開発記録。**

**Limit Development** is the public front door for the development work of `nobutakayamauchi` / あるてぃめっと.

This repository does **not** absorb every implementation into one monolith. It is the public index that explains:

- what Limit Development is;
- what is being built now;
- how the development method evolved;
- what survived, what was destroyed, and what was retired;
- and which canonical repository should be opened next.

Implementation, evidence, history, and detailed technical truth remain canonical in their own repositories.

## Current lineage

```text
Original RTS
  ↓ question whether the system itself is necessary
WITNESS
  ↓ standalone software necessity destroyed
Five surviving principles
  ↓ reconstruct RTS using existing capabilities + surviving responsibilities
RTS Evolution
  ↓ the reconstruction motion itself becomes refined
Ultimate Loop
```

The repeating pattern is:

**build → question necessity → destroy → preserve what survives → reconstruct → refine the reconstruction method itself**
