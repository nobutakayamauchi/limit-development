# 限界開発 / limit-development

**すべてを懸けて、一人の男がスマホ1台でクソッタレな世界と戦う開発記録。**

このリポジトリは、限界開発そのものの実装を抱え込む場所ではありません。

- 限界開発の世界観
- 開発者の公開可能な現在地
- 現在進行中の開発
- 作ったもの / 終了したもの
- 各GitHubリポジトリへの入口

をまとめる **公式インデックス / 玄関** です。

実装・詳細な技術資料・履歴は、それぞれの実リポジトリを正本とします。

## Public pages

- `index.html` — 限界開発トップ / 開発物インデックス
- `status.html` — 開発者の公開可能な現状

## Hero image
